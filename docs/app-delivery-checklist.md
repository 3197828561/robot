# Android App 正式交付清单

本清单用于把一个 App 提交从“代码完成”推进到“测试包可交付”和“三方联调通过”。产品要求
见 [正式化产品需求](requirements/app-formalization-product-requirements.md)。

## 1. App 开发交付

每次交付必须同时提供：

| 交付物 | 必填内容 |
|---|---|
| 源码基线 | 仓库、分支、完整提交哈希 |
| APK | 文件名、渠道、`versionName`、`versionCode`、SHA-256 |
| 构建结果 | 单元测试、Lint、Debug APK；发布时增加签名 Release APK |
| 配置说明 | `local.properties.example` 中需要的键名，不包含真实值 |
| 功能范围 | 本包已完成、未完成和暂不可用功能 |
| 接口基线 | V3 未覆盖部分、V4.3、V5、V6 |
| 回退点 | 可恢复的 Git 提交；已安装 App 回退使用更高 `versionCode` 重发 |
| 问题定位 | App 版本、设备编号、时间、页面、操作步骤和去密日志 |

发布包不得包含调试凭据、模拟设备、示例地图或默认 Robot 身份回退。

## 2. Cloud 配合输入

App 测试前，Cloud 负责人需要确认：

- HTTPS健康检查和证书有效；
- 登录、刷新、退出、用户和设备接口可用；
- 测试账号只绑定本轮真实设备；
- Map V2 current、metadata 和 content 接口可用；
- jobs、Wi-Fi、固件接口的真实完成状态与权限；
- `test` App 发布元数据与 APK 下载可用；
- API 错误使用稳定状态码/错误码，不要求 App 解析内部错误文本；
- 当前部署提交和可用回退点。

Cloud 当前未实现的 Robot 执行闭环必须明确写为“暂不可用”，不能让 App 根据 HTTP 200
推断 Robot 已完成操作。

## 3. Robot 配合输入

Robot 负责人需要提供：

- `crawler/crawler_00000001` 的软件提交、构建时间和模块版本；
- 按 V4.3/V5/V6 实际运行的 Topic、QoS、频率和 Payload 样例；
- heartbeat、status、cmd_ack、pose 发布；
- cmd、remote 消费与命令安全执行；
- Map V2 上传、激活和重启恢复；
- 自动任务、手动模式、遥控超时零速、急停和解除急停闭环；
- V6 遥测真实可用项和当前为空项；
- Robot/ROS 日志与 App 操作时间对应证据。

接口字段不足时先提出文档变更，不临时要求 App 猜测新字段。

## 4. 测试人员交付

每轮测试记录：

- APK版本、SHA-256、设备编号、手机型号、Android版本和测试时间；
- 手机真机测试结果；
- 平板模拟器尺寸、Android版本和结果；
- 每个问题的复现步骤、期望结果、实际结果、截图/录屏和发生时间；
- 控制问题对应的 MQTT、Robot 日志和 Robot 实际动作；
- 回归结果和仍未关闭的问题。

不要只记录“按钮没有反应”，应记录进入页面后的设备状态、按钮状态、点击时间和后续提示。

## 5. App 发布门禁

### 测试渠道

- [ ] P0代码和界面完成；
- [ ] 单元测试通过；
- [ ] Lint通过；
- [ ] Debug APK可安装；
- [ ] Release签名、包名和更新校验通过；
- [ ] 手机冒烟测试通过；
- [ ] 平板模拟器冒烟测试通过；
- [ ] 下载入口能够取得本次版本；
- [ ] 交付说明与实际包一致。

### 合入 `develop`

- [ ] Robot、Cloud、App feature提交固定；
- [ ] `crawler_00000001` 自动与手动控制实机通过；
- [ ] 地图、V6遥测、离线恢复和安全控制通过；
- [ ] P0问题全部关闭；
- [ ] 联调报告包含三方证据；
- [ ] PR审查和自动/本地检查通过。

### 稳定渠道

- [ ] `develop` 回归通过；
- [ ] 从 `release/*` 合入 `main`；
- [ ] SemVer标签、版本说明和回退方案就绪；
- [ ] 固定签名更新安装通过；
- [ ] 稳定下载入口返回正确版本。

## 6. 当前设备验收矩阵

| 场景 | App | Cloud | Robot | 通过证据 |
|---|---|---|---|---|
| 登录和设备选择 | 页面与会话 | 鉴权和绑定 | 无 | UI + HTTP |
| 地图首次同步 | 校验并绘制 | 鉴权下载 | 上传并激活 | UI + HTTP + Robot日志 |
| 自动任务 | 命令和最终状态 | MQTT基础设施 | 规划并执行 | UI + MQTT + 实际动作 |
| 手动控制 | MANUAL、20 Hz、零速 | MQTT基础设施 | 安全执行和超时零速 | UI + MQTT + 实际动作 |
| 急停 | 立即发送和状态反馈 | MQTT基础设施 | 立即安全停止 | UI + MQTT + 实际动作 |
| V6遥测 | 可空解析和展示 | MQTT基础设施 | 采集并上报 | UI + MQTT + 传感器来源 |
| App更新 | 检查、校验、安装 | 元数据和APK | 无 | 旧版升级到新版 |

任何一列缺少证据时，只能标记为对应组件完成，不能标记为联合验收通过。
