# Android App 功能与交接

本文只记录当前有效业务。当前唯一联调设备为 `crawler_00000001`。

## 用户页面与业务结果

| 页面 | 用户操作 | App 展示 | 外部依赖 | 验收重点 |
|---|---|---|---|---|
| 登录 | 输入邮箱和密码、显示密码、记住登录信息、登录 | 登录错误或进入设备列表 | Cloud 登录 API | 凭据仅加密保存在本机，Token 失效可返回登录页 |
| 设备列表 | 选择设备、切换账号、退出 | 只展示有效 Robot 设备 | Cloud 设备列表 | 只能进入 `crawler_00000001`，不得回退到其他设备身份 |
| 首页 | 查看地图和状态、控制任务 | 在线、电量、速度、任务状态、最近命令 | HTTP Map V2、MQTT | ACK 只表示受理，最终结果以 status 为准 |
| 地图 | 缩放、显示全部、居中 | 地图、位置、航向、10 秒轨迹 | HTTP Map V2、MQTT pose | 地图身份不匹配时隐藏位置并重新同步 |
| 手动控制 | 进入手动、设置速度、长按方向、普通停止、急停、切回自动 | 模式、安全状态和不可用原因 | MQTT cmd/remote/status | manual ACK 与 status 均确认后才可移动；松手必须零速 |
| 状态详情 | 查看连接、设备、任务、安全、地图和遥测 | 当前真实状态；离线遥测显示为空 | MQTT heartbeat/status/pose | 不显示上一会话旧状态，不把非法遥测当有效值 |
| 日志 | 筛选、搜索、查看、清空 | App 本地结构化日志 | 本地 Room | 清空只影响本机，不影响 Cloud/Robot |
| 作业记录 | 查看历史结果 | 时间、状态、清洁行数 | Cloud jobs API | 属于运营查询，建议放“更多” |
| Wi-Fi 配置 | 查看 SSID、输入新密码并保存 | 成功或失败提示 | Cloud Wi-Fi API、Robot执行链路 | 属于维护功能，正式使用前需要权限和确认 |
| 固件升级 | 查看最新版本并提交升级 | 版本、说明、提交结果 | Cloud firmware API、Robot升级链路 | 属于维护功能，正式使用前需要权限、确认和进度闭环 |
| App 更新 | 下载并安装新版本 | 新版本说明、下载及安装提示 | Cloud App 发布接口 | 校验大小、SHA-256、包名、版本号和签名 |

## 建议的信息架构

```text
底部导航
├─ 首页：地图预览、核心状态、任务控制、急停
├─ 地图：完整地图、机器人位置和轨迹
├─ 手动控制：模式切换、方向和速度
└─ 状态：任务、安全、连接和遥测

设备设置/更多
├─ 作业记录
├─ Wi-Fi 配置（维护权限）
├─ 固件升级（维护权限）
├─ 本地日志
└─ App 版本信息
```

首页只承载高频状态和控制。Wi-Fi、固件升级等低频高风险操作不得与开始任务、停止任务和急停并列。

## 各方交接内容

### App 开发

- 当前分支和提交、构建命令、测试结果、APK版本和签名一致性；
- 页面操作与 MQTT/HTTP 请求的对应关系；
- 不提交 `local.properties`、密码、Token、JKS 或 Base64；
- 提供失败提示、日志位置和可回退提交。

### Cloud

- 登录、设备、地图、作业、Wi-Fi、固件和 App 更新 API；
- 用户只绑定真实设备 `crawler_00000001`；
- 停用或删除旧 `rk3588` 记录；
- 返回稳定错误码，不能让 App 根据服务器内部错误文本判断业务。

### Robot

- 提供 heartbeat、status、pose、cmd_ack，并消费 cmd、remote；
- 提供当前地图上传/激活信息；
- 证明任务状态、手动模式、零速、急停、解除急停和 V6 遥测字段闭环；
- Wi-Fi 和固件功能若未实现，应由 Cloud 返回“暂不可用”，App不得显示成功。

### 测试人员

- 记录 APK 版本、设备编号和测试时间；
- 按登录、设备选择、地图、自动任务、手动控制、安全控制、离线恢复、更新流程测试；
- 每个控制操作同时保存 App 展示、MQTT `cmd_ack/status` 和 Robot 实际动作；
- 发现问题时提供截图、日志时间和操作步骤。

## 正式验收标准

- 用户能判断当前控制的是哪台设备；
- 不可用按钮有明确原因，不允许误触错误设备；
- 急停立即生效，解除急停需要安全确认；
- App显示、MQTT状态和Robot实际动作一致；
- 离线、超时、拒绝和服务故障都有明确提示；
- 手机和平板横屏界面无重叠、截断或无法点击；
- 新 APK 可通过测试渠道更新，签名与旧版本一致。
